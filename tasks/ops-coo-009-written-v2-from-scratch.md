## Green / Yellow / Red Gate

I separate value from risk. A high value score never overrides a red flag.

Green auto-executes when value is `>=7` `[Assumed]`, source is verified, the action is reversible, the pattern is known, writeback is available, and there are no red flags. Examples: Alfred internal briefings, approved-template Flash repurposing, and existing-page Oracle fixes with verified GSC/GA4 data.

Yellow goes to me, an owner, or a small council when judgment matters but CEO context does not: churn investigation, new-page SEO recommendations, non-ICP prospects, creative refreshes, channel pivots, or paid media restructuring.

Red goes to Eric: pricing, refunds, contracts, strategic accounts, public claims, legal/privacy/security, senior people decisions, new core crons, killing core crons, and CEO-level priority tradeoffs.

The value score uses revenue proximity, time sensitivity, source confidence, owner clarity, effort size, and learning value on a `0/1/2` scale `[Assumed]`. Risk flags are irreversibility, strategic relationship, brand/public exposure, legal/privacy/security, financial exposure, novelty, and low source confidence. When green fails, reverse it if possible, notify the owner, move that item type to yellow, log the failure, and change the rule.

## Operating Edge

HG Market Report replaced manual data retrieval and slide deck assembly with a live customer report, sales presentation, and follow-up sequence. It saves roughly `1-2` hours per sales report `[Estimated applicant claim]` and gives prospects a self-serve path when they want the analysis but do not want to talk to sales.

HG SEO Commander does the same thing on delivery: SEO analysis, reporting, GBP posts, blog posts, link-building deliverables, and reporting. It saves at least `3-4` hours per client per month `[Estimated applicant claim]`. The adoption lesson was simple: people use tools that remove bad work. When a bug created bad GBP posts, someone started deleting them manually. I fixed it through the CLI and showed them how to use the tooling instead. The operating rhythm I installed was source data -> generated analysis/deliverable -> operator review -> customer send/publish -> outcome log. It stuck because the system removed manual deck/report work instead of adding ceremony.

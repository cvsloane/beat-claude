# Ops COO 009 - Lean Attachment Map

Use the smallest reviewer path that still satisfies the brief.

## Submit

1. `written-answer.pdf`
   - Official 2-page answer.
   - Includes LinkedIn URL, number source labels, AI usage disclosure, self-assessment, what breaks it, what stays human, and short evidence log.

2. `supporting-operating-artifact-and-evidence.md`
   - Use only if the portal allows a supporting file.
   - Contains the queue states, daily cadence, cron audit rule, initial cron calls, and proof-tier evidence log.

## Use In Application Fields

- `cover-letter.md`
- `application-answers.md`

## Do Not Upload By Default

- Long proof summaries.
- Image appendices.
- Internal score reviews.
- Raw QuickBooks, payroll, CRM, Slack, client, or ad-account exports.

Detailed proof belongs on `https://csloane.com/numbers` or in a live walkthrough.
